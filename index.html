How this board is kept current

This is a shared, filterable snapshot of English-language sports-TV roles worldwide — presenters, reporters, anchors, MMJs and producers. It is not exhaustive: on-air seats at national networks are frequently filled by direct appointment and never advertised. Contact names, phone numbers and emails are shown where the advert provides them — for most TV roles it does not, and applications route through the broadcaster's own system via the Apply link.

To make the board update itself, the data lives in jobs.json and this page renders it. A scheduled job (e.g. a daily GitHub Action) refreshes that file from sources that expose it cleanly — broadcaster career APIs (Greenhouse, Lever, Workday) and RSS — then redeploys. See SPEC.md for the build.
