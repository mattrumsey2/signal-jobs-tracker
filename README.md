# SIGNAL — Global Sports-TV Jobs Board

A shared, filterable, auto-updating board of English-language sports-TV roles worldwide —
presenters, reporters, anchors, MMJs and producers. Prioritised on **international news
networks**.

- `index.html` — the board (static, no build step). Reads `jobs.json`; falls back to embedded
  seed data if that file is absent.
- `jobs.json` — the data, regenerated by the collector.
- `collector/` — the Node collector (no dependencies, Node 20+).
- `.github/workflows/update.yml` — daily scheduled run that commits `jobs.json` when it changes.
- `SPEC.md` — fuller design notes.

## Quickstart (local, in Claude Code)

```bash
node collector/run.mjs      # pulls live sources, writes jobs.json
# then open index.html (any static server), e.g.:
python3 -m http.server 8000 # → http://localhost:8000
```

> Note: the collector's live pulls need an **open network**. In a locked-down sandbox the
> Workday calls return 403 from the egress proxy and the run falls back to the pinned watch
> rows — that's expected. Run it in Claude Code or CI to populate the on-air listings.

## Deploy (one shareable URL, zero cost)

1. Push this folder to a GitHub repo.
2. **Settings → Pages** → deploy from branch (root). You get `https://<you>.github.io/<repo>/`.
3. **Actions** tab → enable workflows. It runs daily at 06:00 UTC (and on-demand via
   *Run workflow*), refreshing `jobs.json` and redeploying automatically.
4. Share the Pages URL. (Vercel works too if you want a custom domain.)

Watch/verify entries appear on the board as amber "watch" rows so nothing goes silently
missing. To automate one: confirm its ATS, add the endpoint to `collector/sources.json`, set
`enabled: true`, and remove its pinned row from `collector/manual.json`.

## Adding sources

Each entry in `collector/sources.json` is one of four adapter types — `workday`, `greenhouse`,
`lever`, `smartrecruiters` — plus config. Examples:

```jsonc
{ "employer": "X", "adapter": "greenhouse", "enabled": true, "token": "companytoken",
  "brandSite": "https://x.com", "alwaysSport": false }
{ "employer": "Y", "adapter": "lever", "enabled": true, "token": "companytoken" }
```

The collector keeps only on-air/producer titles (see `classifyRole`) and, for general-news
employers, only sport-related roles (`isSport`). Set `alwaysSport: true` for sport-only brands
(e.g. Eurosport) so every on-air role is kept.

## Honest limits

- Not exhaustive — national on-air seats are often filled by direct appointment, never advertised.
- Contact name/phone/email are shown only when an advert lists them; most TV roles route through
  an applicant system and give none.
- Indeed/LinkedIn are deliberately **not** scraped (they block it, technically and in their terms).
  "Comprehensive" here means every source that can be pulled cleanly.
- If a Workday tenant returns 403 even on an open network, add browser-like headers
  (`User-Agent`, `Accept-Language`) in `collector/adapters/workday.mjs`, or fall back to its
  RSS/HTML — noted inline.
